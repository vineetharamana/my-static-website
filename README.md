# Static Website Hosting Using GitHub Pages

## Project Description
This project demonstrates how to create and host a simple static website using GitHub Pages.

## Technologies Used
- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Project Structure

## Steps to Deploy
1. Create a simple website using HTML and CSS.
2. Create a repository on GitHub.
3. Upload the website files to GitHub.
4. Open the repository Settings.
5. Go to Pages.
6. Select the `main` branch and `/(root)` folder.
7. Click Save and wait for deployment.
8. Open the live website link.
